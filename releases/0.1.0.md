# Новое

## Установка одной командой

Gentry ставится одной командой в терминале: скрипт скачивает программу для вашей платформы, сверяет её контрольную сумму с выпуском и добавляет папку программы в PATH. Права администратора и Go не нужны.

### Вкладка: Linux и macOS

```
$ curl -fsSL https://github.com/t8nax/gentry/releases/latest/download/install.sh | sh
+ Gentry 0.1.0 установлен.
Программа: /home/anna/.gentry/bin/gentry
Папка добавлена в PATH в файлах:
  /home/anna/.profile
  /home/anna/.bashrc

Открыть новое окно терминала и подключить ИИ-инструмент: gentry setup <ИИ-инструмент>
Посмотреть доступные ИИ-инструменты: gentry setup --help
```

### Вкладка: Windows

```
$ irm https://github.com/t8nax/gentry/releases/latest/download/install.ps1 | iex
+ Gentry 0.1.0 установлен.
Программа: C:\Users\anna\.gentry\bin\gentry.exe
Папка добавлена в переменную Path пользователя.

Открыть новое окно терминала и подключить ИИ-инструмент: gentry setup <ИИ-инструмент>
Посмотреть доступные ИИ-инструменты: gentry setup --help
```

### Вкладка: Повторная установка

```
$ curl -fsSL https://github.com/t8nax/gentry/releases/latest/download/install.sh | sh
+ Gentry 0.1.0 установлен.
Программа: /home/anna/.gentry/bin/gentry
Прежняя версия: 0.1.0
Папка уже есть в PATH.

Подключить ИИ-инструмент: gentry setup <ИИ-инструмент>
Посмотреть доступные ИИ-инструменты: gentry setup --help
```

## Установка нужной версии

Параметр `--version` ставит выбранный выпуск, в том числе прежний, если с новым что-то не так. На Windows параметр называется `-Version`.

### Вкладка: Linux и macOS

```
$ curl -fsSL https://github.com/t8nax/gentry/releases/latest/download/install.sh | sh -s -- --version 0.1.0
+ Gentry 0.1.0 установлен.
Программа: /home/anna/.gentry/bin/gentry
Папка добавлена в PATH в файлах:
  /home/anna/.profile
  /home/anna/.bashrc

Открыть новое окно терминала и подключить ИИ-инструмент: gentry setup <ИИ-инструмент>
Посмотреть доступные ИИ-инструменты: gentry setup --help
```

### Вкладка: Такой версии нет

```
$ & ([scriptblock]::Create((irm https://github.com/t8nax/gentry/releases/latest/download/install.ps1))) -Version 0.9.0
! Выпуск не найден.
Версия: 0.9.0

Посмотреть выпуски: https://github.com/t8nax/gentry/releases
```

## Установка без изменения PATH

Параметр `--no-modify-path` ставит программу, но не меняет PATH и файлы настройки оболочки: папку программы можно добавить самостоятельно. На Windows параметр называется `-NoModifyPath`.

### Вкладка: Linux и macOS

```
$ curl -fsSL https://github.com/t8nax/gentry/releases/latest/download/install.sh | sh -s -- --no-modify-path
+ Gentry 0.1.0 установлен.
Программа: /home/anna/.gentry/bin/gentry
PATH не изменён.

Добавить папку в PATH: /home/anna/.gentry/bin
Подключить ИИ-инструмент: /home/anna/.gentry/bin/gentry setup <ИИ-инструмент>
Посмотреть доступные ИИ-инструменты: /home/anna/.gentry/bin/gentry setup --help
```

### Вкладка: Windows

```
$ & ([scriptblock]::Create((irm https://github.com/t8nax/gentry/releases/latest/download/install.ps1))) -NoModifyPath
+ Gentry 0.1.0 установлен.
Программа: C:\Users\anna\.gentry\bin\gentry.exe
PATH не изменён.

Добавить папку в PATH: C:\Users\anna\.gentry\bin
Подключить ИИ-инструмент: C:\Users\anna\.gentry\bin\gentry.exe setup <ИИ-инструмент>
Посмотреть доступные ИИ-инструменты: C:\Users\anna\.gentry\bin\gentry.exe setup --help
```

## Страница каждого выпуска

У каждого выпуска есть своя страница — такая, как эта: что изменилось, что сделать при обновлении и примеры новых возможностей. Все выпуски собраны в [списке выпусков](https://t8nax.github.io/gentry/).

## Обновление одной командой

Команда `gentry update` ставит последний выпуск Gentry, обновляет плагин Gentry в подключённых ИИ-инструментах и субагентов в рабочих копиях. После обновления она показывает несовместимые изменения пропущенных версий — то, что нужно сделать самому, — и ссылку на страницу выпуска.

### Вкладка: Последняя версия уже стоит

```
$ gentry update
+ Установлена последняя версия Gentry.
Версия: 0.1.0
```

### Вкладка: Когда выйдет новая версия

```
$ gentry update
+ Gentry обновлён: 0.1.0 → 0.2.0
Изменения вступят в силу в новых сессиях ИИ-инструментов.

Страница выпуска: https://t8nax.github.io/gentry/0.2.0/
```

  и примеры новых возможностей.
* Обновление одной командой: Gentry обновляется сам вместе с плагином
  и субагентами и показывает, что нужно сделать после обновления.
