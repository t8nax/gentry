Отмена освобождает рабочую копию задачи. Gentry не изменяет код в копии, поэтому отмена с незакоммиченными изменениями отклоняется.

Программа: `<gentry>`. В командах ниже `gentry` — эта программа.

1. Отменять задачу только по слову оператора. Если оператор назвал причину, передать её обоснованием: `gentry task cancel --reason <обоснование>`.
2. Если отмена отклонена из-за незакоммиченных изменений, посмотреть изменения в git и коротко пересказать оператору, что изменено по существу.
3. Спросить, что сделать с изменениями: закоммитить в текущую ветку или удалить. Для разных файлов решение может быть разным. Для коммита предложить сообщение.
4. Удалять изменения только после прямого слова оператора на удаление: удаление необратимо. Не откладывать изменения в git stash.
5. Выполнить решение оператора и снова отменить задачу.
6. Если оператор решил оставить изменения, сообщить, что задача не отменена.

Ветку рабочей копии не переключать. Отменённую задачу можно взять заново: `gentry task take --task <задача> --scenario <сценарий>`.
