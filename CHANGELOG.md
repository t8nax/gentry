# Журнал изменений

## Не выпущено

### Новое
* Добавлено подключение к Codex командой `gentry setup codex`: она ставит плагин Gentry
  со скиллами и инструментами, хук запуска сессии и настраивает Codex для работы с Gentry.
  Задачи по флоу можно вести и продолжать между ИИ-инструментами; на Windows команды
  с полным путём программы из подсказок Codex выполняются в PowerShell, включая пути
  с пробелами и специальными символами.
* Добавлена раскладка субагентов флоу в формате Codex — в `.codex/agents` рабочих копий.

### Изменено
* `gentry update` теперь обновляет и интеграцию с Codex, если она подключена.
* Раскладка субагентов теперь идёт только в формате подключённых ИИ-инструментов:
  без `gentry setup claude` файлы `.claude/agents` не раскладываются, а `gentry agents deploy`
  сообщает, что ИИ-инструменты не подключены.
* `gentry project add` и `gentry worktree add` теперь доверяют рабочие копии в Codex,
  если Codex подключён.
* Команды Gentry, выполненные в оболочке сессии Codex, теперь записывают изменения как агент.
* `gentry setup claude` и `gentry setup codex` теперь раскладывают субагентов
  во все рабочие копии подключённых проектов после установки, обновления
  или переключения плагина. Повторный `setup` без изменения плагина
  раскладку не запускает.

### Исправлено

* Исправлен откат неудачного первого `gentry setup claude`: Claude Code больше не считается подключённым, а созданные этим вызовом папка интеграции и marketplace удаляются по возможности.

## 0.1.0 — 2026-10-19

Первый выпуск: Gentry ставится одной командой и обновляется командой `gentry update`.

### Новое
* Добавлена установка одной командой: на Linux и macOS —
  `curl -fsSL https://github.com/t8nax/gentry/releases/latest/download/install.sh | sh`,
  на Windows — `irm https://github.com/t8nax/gentry/releases/latest/download/install.ps1 | iex`.
  Права администратора и Go не нужны.
* Добавлена установка конкретной версии параметром `--version`
  (на Windows — `-Version`), в том числе возврат на прежнюю.
* Добавлена установка без изменения PATH параметром `--no-modify-path`
  (на Windows — `-NoModifyPath`).
* Добавлена страница каждого выпуска: что изменилось, что сделать при обновлении
  и примеры новых возможностей — `https://t8nax.github.io/gentry/<версия>/`.
  Список всех выпусков — `https://t8nax.github.io/gentry/`.
* Добавлена команда `gentry update`: она ставит последний выпуск Gentry,
  обновляет интеграции с подключёнными ИИ-инструментами и субагентов в рабочих
  копиях и показывает несовместимые изменения.
